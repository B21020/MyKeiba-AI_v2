## Objective

P11-top200 の RR=1.072 をベースに、正則化を強化して AUC gap を縮小し汎化性能を向上させる。

## Analysis

### なぜ正則化強化は失敗したか

1. **AUC gap は改善された**: 0.179 → 0.054 (70%削減) — 正則化は過適合抑制に確実に効いた
2. **しかしエッジも消失**: RR 1.072 → 0.924 — テスト AUC は同じ (0.749) なのに RR が大幅低下
3. **Validation-Test 乖離**: Validation best RR=1.073 → Test best RR=0.924 — HPO 自体の過適合
4. **Default が HPO を上回る**: Default RR=1.084 (th=2.975) vs HPO RR=0.924 — HPO が有害

### 根本的な問題

- **P11-top200 のエッジ (RR=1.072) はモデル複雑性に依存**: num_leaves=123, max_depth=6 の高複雑度モデルでのみ発現
- **正則化するとエッジが消える**: 正則化は汎化改善するが、エッジを生む「過学習的パターン」も同時に消す
- **AUC gap ≠ RR 改善**: AUC gap を小さくしても RR が改善されるとは限らない
- **エッジの源泉が「ノイズフィッティング」の可能性**: 過適合によるスコア分離がエッジの実体かもしれない

### P11-top200 との比較から得られる教訓

| 観点 | P11-top200 | P12 | 示唆 |
|---|---|---|---|
| 複雑性 | 高 (leaves=123, depth=6) | 中 (leaves=43, depth=4) | エッジは複雑モデルに依存 |
| AUC gap | 0.179 (過適合あり) | 0.054 (過適合小) | 過適合抑制 ≠ 収益改善 |
| min_split_gain | 0.149 | 1.675 | 高 split_gain が最適 → 正則化は効いている |
| 閾値 | 3.598 (極端) | 2.935 (緩い) | エッジは極端閾値のみに存在する構造は変わらず |

## Conclusion

**P12: ❌ 失敗**

正則化強化は AUC gap 改善 (0.179→0.054) には成功したが、エッジ自体が消失 (RR 1.072→0.924)。
P11-top200 のエッジはモデル複雑性に依存しており、正則化で汎化を改善するとエッジも同時に失われる。

これは**エッジの正体がモデル過適合によるスコア極端化**である可能性を示唆する。
真のエッジ (汎化可能なエッジ) は現在のモデル・特徴量では発見できていない可能性がある。
