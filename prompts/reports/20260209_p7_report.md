- **キャリブレーションなしが最良** = HPO で already well-calibrated な確率を出力

## P7-2: rel_ext_rank Model HPO (複勝戦略)

### Optuna HPO 結果
- **Trials**: 150 (TPESampler, seed=42)
- **所要時間**: 1,725秒 (29分)
- **AUC(valid)**: 0.758019 → **0.763437 (+0.005418)**
- **AUC(test)**: 0.7479 → **0.7528 (+0.0049)**

### Best Hyperparameters
```json
{
  "num_leaves": 27,

  "learning_rate": 0.0412,
  "n_estimators": 600,
  "min_child_samples": 81,
  "subsample": 0.806,
  "subsample_freq": 0,
  "colsample_bytree": 0.753,
  "reg_alpha": 4.867,
  "reg_lambda": 0.00115,
  "min_split_gain": 0.705
}
```

### Full Sweep 結果

| Combo | AUC(test) | fukusho RR | fukusho n | edge RR | edge n |
|---|---|---|---|---|---|
| hpo_none | 0.7528 | 0.928 | 142 | 0.666 | 9,811 |
| hpo_platt | 0.7528 | 0.952 | 99 | 0.681 | 9,788 |
| hpo_isotonic | 0.7528 | 0.974 | 53 | 0.686 | 9,823 |
| default_none | 0.7479 | 0.970 | 134 | 0.700 | 9,802 |
| default_platt | 0.7479 | **0.978** | 68 | 0.695 | 9,614 |
| **default_isotonic** | **0.7479** | **0.991** | **188** | 0.676 | 9,698 |

**HPO vs Default (fukusho)**: -0.018 (0.974 vs 0.991) → **HPO 逆効果**

### 分析: なぜ HPO が逆効果だったか
1. **AUC改善 ≠ betting RR改善**: AUC は全体的なランキング精度、RR はテール部分の精度
2. **Default params の過学習**: train AUC=0.851 vs HPO=0.843。Default の方がやや過学習しているが、isotonic calibration がそれを補正し、テール部分の確率推定が好ましい分布になった
3. **n の減少**: HPO isotonic n=53 vs Default isotonic n=188。HPO が閾値を超える馬を絞りすぎ
4. **結論**: 複勝戦略には default params + isotonic calibration が最適
