# P11: 特徴量選択 (Feature Selection) — 実験レポート

**Date**: 2026-02-10
**Status**: ✅ 部分的成功 — 過適合大幅改善 + Top-200 で歴代最高 RR=1.072

---

## 概要

P10 で特徴量「追加」がノイズ増加と性能悪化を招いた教訓を受け、
逆方向のアプローチ「特徴量選択（削減）」を実施。
LightGBM gain importance + permutation importance の2軸で特徴量をランキングし、
top-200 / top-100 / top-50 の段階的サブセットで HPO + Bootstrap 評価を行った。

**元データ (342 cols) は一切変更せず、選択リストを JSON で管理。**

### 重要な発見

#### ✅ Top-200: 歴代最高 RR

- **RR = 1.072 (n=60)** — P9-2 の 1.059 を上回る歴代最高
- **P(RR<1) = 0.352** — P9-2 の 0.358 とほぼ同等
- th=3.498 で n=113, RR=1.043, P(RR<1)=0.402 → **中程度 bet 数でもプラス**
- **2026-01: +9.2** の大勝利月が寄与 (ただし集中リスク)

#### ✅ Top-100: 過適合抑制に最も成功

- **AUC gap = 0.038** — 全フェーズ最小の過適合
- max_depth=3, colsample_bytree=0.30 の強い正則化
- Hit rate 71.0% だが配当が低い → RR は 0.942
- 全 threshold で n≥100 のRR>1.0 は達成できず

#### Top-50: 特徴量不足

- RR=0.942 で Top-100 と同等だが CI 幅が拡大
- 50 features では情報量不足の兆候
- 月別: 2025-02 (-4.0) の大損失が目立つ

## 結論

### ✅ P11 は部分的成功

1. **Top-200 で歴代最高 RR=1.072 (n=60)** — P9-2 (1.059) を上回る
2. **初めて n>100 で RR>1.0**: Top-200 の th=3.498 で n=113, RR=1.043
3. **過適合抑制**: Top-100 で AUC gap 0.038 (P9-2: 0.246 の 85% 削減)
4. **統計的有意性は未達**: P(RR<1)=0.352 (Top-200 best) — 依然として有意でない

### 教訓

- **特徴量削減は過適合抑制に極めて有効** (gap 0.246→0.038)
- **しかし過適合抑制 ≠ エッジ改善**: Top-100 は最小 gap だが RR<1
- **Top-200 が最適バランス**: 十分な情報保持 + 適度なノイズ削減
- **335→200 への削減で 80 ゼロ gain + 55 の低重要度ノイズを除去**
- **n≥300 では依然として RR<0.9**: 構造的に大量ベットは不可能

### 次のアプローチ

Top-200 をベースに:
- **P9-6 + Top-200**: 正則化強化 (max_depth=3-6 制限) + 特徴量選択の組み合わせ
- **positive_perm (145 cols)**: perm>0 の特徴量のみで実験
- **Top-200 + more trials**: 100→200 trials での探索強化
