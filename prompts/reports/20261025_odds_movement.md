# 発走6分前から確定までのオッズの動きは、6分前の時点で読めるか

前提：[段階2の再比較（6分前の市場）](20261024_stage2_t6.md)、[複勝の市場](20261025_place_market.md)。実施日：2026年10月25日。

## 結論

**読めない。** 確定の市場は6分前の市場より勝ち馬をよく当てる（ΔR² +0.0193、95%区間 +0.0157〜+0.0228）。しかし、6分前までに分かること（それまでのオッズの動き、複勝と単勝の食い違い）を足しても、取り戻せるのはその差の 1〜2% 程度。区間は0をまたぐ。

- **動きの大きさは、半分近く予測できる。** move = log q（確定） − log q6 の分散のうち約45%は、6分前の確率の高さだけで予測できる。人気薄ほど確定で確率が下がる（13〜18番人気で平均 −0.37、確率が約3割減る）。それまでの動きを足すと 46% まで上がる。
- **しかし、予測できる部分は勝ち馬の情報ではない。** 予測できるのは「市場全体が人気側に締まる」形の変化で、条件付きロジットの [log q6] の係数（≈1）がすでに吸収している。勝ち馬を当てる力は、動きを足しても変わらない（+0.0003、−0.0018〜+0.0023）。
- **差の大半は、最後の5分に届く。** 市場の当たり具合（補正なしの pseudo-R²）の推移:
  - 2時間前 0.228
  - 6分前 0.241
  - 1分前 0.257
  - 確定 0.259
  
  6分前から確定までの差 0.019 のうち、0.017（約9割）は6分前と1分前の配信の間に入ってくる。
- **購入：6分前に、予測した確定オッズで期待値を計算して単勝を買うと損をする。**
  - 主な規則（全特徴・閾値1.00）：7,167回、回収率75%（56〜98%、区間が100%未満）
  - 予測では人気薄のオッズが上がる（確率が下がる）ので、期待値が1を超えるのは人気薄ばかりになる（当たり率1.5%）。人気薄は本命・大穴の偏りで回収率が低い。

→ 確定の市場の優位は、最後の数分に入る新しい情報（直前の大口の投票など）によるもので、6分前までのオッズの形からは前もって読めない。

## 方法

- 対象：段階0の評価対象で、6分前の単勝・複勝オッズが全頭そろい、確定の単勝オッズがあるレース。開発期間 2025年11月〜2026年6月の2,110レース・30,421頭。最終確認期間（2026-07-01 以降）は読んでいない。
- 時系列オッズ（JV-Link 0B41）の配信：前日夕方から約5分ごと、発走直前は 11分前・6分前・1分前。発走 k 分前の値は「k 分前までに配信された最新」とした。そのため10分前 = 11分前の配信、5分前 = 6分前の配信、0分前 = 1分前の配信になる（`tools/run_odds_movement.py` の `asof_from_quotes`）。
- 特徴（どれも6分前までの配信だけ）:

  | 特徴 | 内容 |
  |---|---|
  | log_q6 | 6分前の単勝の市場確率（レース内で正規化） |
  | mom_10・mom_30・mom_120 | 6分前の log q − 10・30・120分前の log q |
  | mom_open | 6分前の log q − 最初の配信の log q |
  | place_gap | logit(複勝オッズから逆算した確率) − logit(単勝から Harville で出した確率)。最低払戻に張り付いた馬は0 |

  前日の最初の配信では、まだ票が入っておらずオッズの無い馬が多い（オッズがあるのは32%）。無い馬は mom_open = 0。
- 確定の log q：確定に残った同じ馬の集合で正規化し直した。
- 区切り：`tools/run_stage2_t6.py --rolling` と同じ3つ（calib 2か月で推定 → outer 2か月で評価。評価 2026年1〜2月・3〜4月・5〜6月、計1,580レース）。
- 動きの予測：最小二乗。R² は「0を予測する」場合を基準にした。
- 勝ち馬：条件付きロジット。ΔR² はレース単位の再標本化で区間を出す。
- 購入:
  - 期待値 = 勝つ確率 × 予測した確定オッズ（6分前のオッズ × exp(−予測した move)）。
  - 閾値は事前に決めた4つ（1.00／1.05／1.10／1.20）。主な判定は全特徴・1.00。
  - 払戻は確定の単勝払戻。開催日単位の再標本化で区間を出す。

## 読み方の注意

- 1分前の配信の後に投票できるかどうかは、発売の締切時刻と配信の遅れによる（未確認）。1分前の市場は確定にほぼ追いつく（差 0.002）。ただし、それは「市場に追いつく」だけで、市場を上回る材料にはならない。
- 動きの予測は最小二乗の線形で、特徴も少ない。非線形のモデル（勾配ブースティングなど）なら動きの R² は上がり得る。ただし、勝ち馬を当てる力の上積みが1〜2%の範囲から大きく変わるとは考えにくい。予測できる部分は市場全体の形の変化で、確率の係数が吸収しているため。
- 票数（売れた金額）は使っていない（収集した列に無い）。直前の大口の投票の大きさは、票数の変化で読める可能性がある。

## これまでの検証のまとめ

6分前の市場を超える情報は、次のどれからも見つかっていない:
- 能力モデル（どの版も）
- 走破能力指数
- 調教
- 複勝の市場
- 6分前までのオッズの動き

確定の市場が持つ +0.019 の優位は最後の数分に入ってくるもので、6分前の時点では使えない。

## 次の一手（案）

1. **判断の時刻を遅らせられるか確かめる**：JRA の発売締切と、0B41 の1分前の配信が届く時刻を確認する。1分前の市場で判断できれば、確定との差は 0.002 まで縮む。ただし、市場に勝つ材料は別に要る。
2. **票数を使う**：O1 レコードの票数合計や、O1 以外の票数のデータ種別を取り込み、直前の大口投票の兆候を見る。
3. 方針の見直し：公開情報と市場の形からは、市場を超える情報が見つかっていない。回収率100%超えを目標にし続けるか、目標を「損を小さく保ったまま検証の仕組みを残す」に変えるかを検討する。
