## 3. 詳細分析

### 3a. Edge-based 単勝 (baseline_win / no cal)

| edge閾値 | RR | n_bets | std |
|---|---|---|---|
| 0.150 | 0.916 | 927 | 0.158 |
| 0.138 | 0.899 | 1,147 | 0.144 |
| 0.126 | 0.875 | 1,419 | 0.125 |
| 0.122 | 0.854 | 1,531 | 0.117 |

- RR は閾値に対して単調減少（高閾値=厳選=高RR）
- n=927でRR=0.916 — P5の edge best (RR=0.77, rank model) から大幅改善
- **win model の edge 戦略が単勝では最も有望**

### 3b. 複勝 threshold (rel_ext_rank / isotonic) — 最安定

| 閾値 | RR | n_bets | std |
|---|---|---|---|
| 3.15 | 0.991 | 188 | 0.072 |
| 3.11 | 0.987 | 221 | 0.073 |
| 3.08 | 0.970 | 260 | 0.065 |
| 3.04 | 0.918 | 302 | 0.059 |
| 2.97 | 0.899 | 403 | 0.048 |
| 2.86 | 0.859 | 579 | 0.038 |

- n=188~260 で RR=0.970~0.991 — **ほぼ損益分岐**
- 曲線が滑らかで、過学習でなく真のシグナル
- **rel_ext features + isotonic calibration が複勝の鍵**

### 3c. 複勝 threshold (rel_ext_win / no cal)

| 閾値 | RR | n_bets | std |
|---|---|---|---|
| 3.46 | **1.000** | 66 | 0.151 |
| 3.43 | 0.884 | 89 | 0.119 |
| 3.32 | 0.873 | 159 | 0.077 |

- RR=1.0 は n=66, std=0.15 → **信頼区間は 0.85~1.15 程度**
- 閾値を一段下げると急落 → 頂点は脆弱
- 3b (rel_ext_rank/isotonic) のほうが安定

### 3d. 複勝EV戦略 (score × odds ≥ th)

| Config | Best RR | n_bets | std |
|---|---|---|---|
| rel_ext_win / platt | 0.705 | 11,665 | 0.022 |
| rel_ext_win / isotonic | 0.691 | 14,057 | — |
| baseline_win / isotonic | 0.683 | 13,376 | 0.023 |

- threshold-only（3b）より劣る結果
- 単勝オッズを複勝EVの代理変数とした設計が不十分
- **→ 複勝オッズ情報の別途取得が必要**

## 6. 重要な知見

1. **win model は単勝戦略に劇的効果**: edge RR が 0.69→0.92 へ +0.23 改善
2. **rel_ext features は複勝に必須**: isotonic calibration と組み合わせてRR=0.99達成
3. **最適戦略はモデル分離**: 単勝 → win model / 複勝 → rank model (rel_ext+isotonic)
4. **複勝EV戦略は再設計必要**: 単勝オッズ代理では不十分。複勝オッズの直接利用が必要
5. **RR>1.0 未達**: 最善でも 0.99 (fukusho) / 0.92 (tansho)。あと一歩
