# P8-1 Report: Edge RR=1.025 統計的頑健性の精密評価

**Date**: 2026-02-09  
**Verdict**: ✗ **統計的に有意でない → 本番投入は見送り推奨**

---

## 1. Executive Summary

P7で達成した edge RR=1.025 (th=0.138, n=695) の統計的頑健性を、Bootstrap CI (2000回リサンプリング) + Fine-grain sweep (36閾値) + 月別/場別 breakdown で評価した。

**結論**: RR>1.0 は統計的に有意でない。

| 黒字月率 | 8/18 (44%) | ≈ 五分五分 |
| 場別集中 | 中山が利益の67% | 過度な依存 |

## 8. Structural Issues

### 8-1: 「2025年3月問題」
- 2025-03 単月で +100.3 の利益（全体利益の **5.6倍**）
- この月を除くと **全期間が赤字 (-82.3)**
- → P7 の edge RR=1.025 は実質的に **1レース月の当たりに依存**

### 8-2: 「中山集中問題」
- 中山競馬場のみで +121.5（10場中1場が利益の大半）
- 他の主要場（東京、阪神）は一貫して赤字
- → 場ごとに別戦略が必要な可能性

### 8-3: 的中率の問題
- 693 bets / 40 hits → **的中率 5.8%**
- 的中1回の影響が全体 RR を大きく変動させる
- Bootstrap CI の幅 ≈ 0.77 はこの低的中率に起因

## 10. Recommendations

### 本番投入について
- **現状の edge strategy をそのまま本番投入するのは非推奨**
- n=693, 的中率5.8% の単勝戦略では、期間・場所の偏りに強く影響される

### 今後の方向性

| # | 施策 | 概要 | 期待 |
|---|---|---|---|
| A | **場別フィルタ** | 中山・京都・小倉のみに限定して edge 戦略を適用 | RR 改善の可能性あるが n が減りさらに CI 拡大 |
| B | **複勝 EV 再挑戦** | 的中率 ≈ 30% で Bootstrap CI が大幅に狭くなる | n=188 → もっとサンプル必要 |
| C | **特徴量改善** | P5 で +0.017 だった rel features の拡張 | AUC 改善 → 的中率改善 → CI 縮小 |
| D | **長期データ蓄積** | test期間を延長して n を増やす | 最も確実だが時間がかかる |
| E | **Ensemble** | win + rank のブレンドモデル | 分散低減の可能性 |
